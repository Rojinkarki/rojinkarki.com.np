AEGIS Enterprise Cyber Range

A small enterprise, built for hands-on security testing.

Context

An isolated VirtualBox environment connects identity, endpoints, a firewall, and monitoring tools so I can trace events from their source to a central investigation workflow.

03 / Public simulation · Completed
Project case study

ARES-1 Mars Colony Cyber Defense

Protecting critical systems through segmentation.

Context

This Cisco Packet Tracer exercise treats a simulated oxygen controller as critical infrastructure. It tests whether ordinary rover or research traffic can reach that system if a device is compromised.

Stack & tools

Cisco Packet Tracer · VLANs · ACLs · Port security

Network controls and test scenarios

  • Separated rover, research, telemetry, control, security, and life-support systems into six main VLANs.
  • Configured router-on-a-stick inter-VLAN routing, extended ACLs, sticky MAC switch security, and VLAN 999 for unused ports.
  • Tested a compromised rover attempting to reach the oxygen controller and a rogue device connecting to a protected switch port.
  • Verified that these unauthorized paths were blocked while intended communication remained available.
Current result & status

Both blocked-access scenarios are documented in the simulated topology. This is a Packet Tracer validation, not a production deployment.

05 / Public simulation · Completed
Project case study

Shree Yasam Campus Network

Two campuses with a clear path between departments.

Context

A Cisco Packet Tracer network design for a school with multiple departments, separated traffic, shared services, and communication between campuses.

Stack & tools

Cisco Packet Tracer · VLANs · Layer 3 · RIP v2 · DHCP

Topology and services

  • Segmented departments and labs into separate VLANs and configured inter-VLAN routing through Layer 3 switches.
  • Used RIP v2 between the two campus networks and static routes toward simulated external connectivity.
  • Configured DHCP and simulated internal web and FTP services plus external email access.
  • Applied hierarchical design and switch security settings to make the topology easier to manage and troubleshoot.

From the original portfolio

Designed and implemented a scalable enterprise network connecting two campuses, providing secure communication, VLAN segmentation, and centralized network services.

  • Designed an enterprise network supporting 8+ departments.
  • Configured VLAN segmentation and Inter-VLAN Routing using Layer 3 switches.
  • Implemented RIP v2 dynamic routing between campuses.
  • Configured DHCP for automatic IP address allocation.
  • Implemented static routing for secure cloud server connectivity.
  • Applied switch security best practices and hierarchical network design.

Tools noted there: Cisco Packet Tracer, Networking, VLAN, Layer 3, RIP v2, DHCP.

Current result & status

The public repository contains the topology and design material. It is a simulated campus network.
